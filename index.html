Point attaches · Path carries · Plane hosts
Primitives0D · 1D · 2Di
Drag a Point onto a Path, a Plane boundary, or a Wire and it sticks there as an attachment. Drag it inside an open Plane and it is hosted. A Plane starts with no built-in points; a typed Component is a Plane with template defaults.
Wirescarry connectionsi
A Wire is a carrier Path. Each end is bound to a Point or free: drag an end handle onto a Point to bind it, or anywhere else to free it. Both ends bound and sharing a surface is a connection; a Point dropped on a Wire is a tap.
