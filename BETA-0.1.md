# 0.1 Beta.24 checkpoint

Status: **RC HARDENING CANDIDATE — NOT YET REPOSITORY-SETTLED**

Beta.24 is the current local convergence checkpoint for the public 0.1 line. It combines host surfaces, editor utilities, file/API/MCP contracts, paired light/dark palettes, Read/Write semantics, canonical 0D attachment points, and explicit regression/performance/mutation gates.

## Candidate primitive boundary

- Components are host-independent semantic entities; backdrop is presentation.
- 0D attachment points are authoritative for Port-like behavior.
- 1D-hosted and 2D-hosted points share the same interaction/legality model; geometry is the intentional difference.
- Built-in dimensional attachment sets are **defaults, not a universal cardinality maximum**; 2D templates already have a small data-declared boundary-point seam.
- Root/Component/carrier receptive surfaces share settle/hosting; carrier placement uses normalized 1-D `t`.
- Direction, Read/Write access, channel, and authority are separate axes.
- Packet animation is projection; it does not independently own path geometry.
- `.sov` / `.sovpak`, Browser CRUD, HTTP/MCP and editor legality share the transport-neutral data core.
- history/checkpoints/clipboard/pin/lock/hidden/opacity/search/appearance/rate are part of the 0.1 editor kernel.
